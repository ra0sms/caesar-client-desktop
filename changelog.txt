CAESAR Desktop - Changelog
==========================

v1.2.0 (2026-09-23)
-------------------
- Add: automatic CW (Morse code) decoder based on the DeepCW neural model
  (morse/deepcw/, run with onnxruntime) — decodes reliably on weak signals,
  in heavy noise and through QSB
- Add: decoded text appears character by character (~1 s after each character)
  in a live one-line scrolling ticker, with a separator between transmissions
- Add: automatic beat-tone detection (300–1250 Hz; tones outside the model's
  400–1200 Hz band are frequency-shifted into it) and automatic WPM estimate
- Add: RX audio tap branch (tee + fdsink) in audio/rx.py — decoded PCM is branched off
  to the CW decoder without touching the playback path or the network stream
- Add: CW Decoder panel in MainWindow (enable checkbox, detected tone display,
  WPM estimate, Clear) and gui/marquee.py — single-line scrolling ticker ("бегущая строка")
- Add: morse_enabled setting persisted to config
- Add: offline self-test (python -m morse.self_test) that sweeps tones/WPM/noise
- Add: optional diagnostic trace for the decoder (CAESAR_MORSE_DEBUG=<path>,
  also dumps the raw decoder input audio)
- Perf: neural inference runs in its own thread; the RX reader thread only buffers audio
- Fix: CAT virtual serial port (PTY) is now owner-only (0600) instead of world-writable
- Deps: added numpy and onnxruntime; build scripts bundle the model and onnxruntime
- License: the DeepCW model is AGPL-3.0 (see morse/deepcw/LICENSE and README.md)
- Quality: added .gitignore; remaining comments and docstrings translated to English

v1.0.7 (2026-08-09)
